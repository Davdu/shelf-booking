# brAIn lab branding

This fork of [Shelf](https://github.com/Shelf-nu/shelf.nu) is rebranded for the
brAIn lab at the IT University of Copenhagen. The changes live on the
`brainlab` branch, which starts from the upstream release tag `shelf@2.4.0`.

**Nothing touches the database.** No Prisma schema or migration changes, so the
image runs against the existing data exactly like upstream 2.4.0 (299 migrations).

### Deliberately left alone

- **Data contracts**: `@deleted.shelf.nu` (soft-deleted users), the
  `x-shelf-organization` API header, CSV header synonyms like "shelf qr id",
  cookie and storage keys. Changing these would break existing data or clients.
- **Founder letters** (`emails/stripe/welcome-to-trial.tsx`,
  `emails/onboarding-email.tsx`): personal emails from Shelf's co-founder.
  They are only sent with premium features or `SEND_ONBOARDING_EMAIL` on, both
  off here.
- **Help links** to `shelf.nu/knowledge-base/...` ("Learn more" links): kept,
  since they are the only documentation for those features.
- Code comments, identifiers (`ShelfError`, `shelf.config.ts`) and the
  companion/docs apps, which are not part of the web image.

## Regenerating the images

```bash
pip install cairosvg pillow
python3 branding/build_assets.py
```

Source files: `brAInLab-logo2024.svg` (all logo variants as Inkscape layers)
and `itu-atrium-cover.jpg`.

## Building the image

Pushing a tag named `shelf@<version>` runs `.github/workflows/build.yml`, which
publishes `ghcr.io/davdu/shelf-booking:<version>` for amd64 and arm64:

```bash
git tag shelf@2.4.0-brainlab.1
git push origin shelf@2.4.0-brainlab.1
```

## Upgrading to a new Shelf release

```bash
git remote add upstream https://github.com/Shelf-nu/shelf.nu.git   # once
git fetch upstream --tags
git checkout brainlab
git rebase --onto shelf@<new> shelf@2.4.0 brainlab
```

Then:

1. Re-run `branding/build_assets.py` (new upstream images overwrite ours on conflict).
2. Search for new user-facing "Shelf" text: `grep -rn "\bShelf\b" apps/webapp/app --include=*.tsx`.
3. Push a new tag, e.g. `shelf@<new>-brainlab.1`.
